# Установка Geant4 на Manjaro

Этот маршрут выполняется после установки и базовой настройки Manjaro.

Здесь устанавливаются инструменты для сборки пакетов из AUR, менеджер `yay` и сам Geant4.

## 1. Обновление системы

Перед установкой обновите систему:

```bash
sudo pacman -Syu
```

Дождитесь завершения обновления. Если обновилось ядро или большое количество системных пакетов, перед продолжением лучше перезагрузить компьютер.

## 2. Установка инструментов для сборки

Для сборки пакетов из AUR нужны стандартные инструменты разработки, Git и CMake.

Установите их командой:

```bash
sudo pacman -S --needed base-devel git cmake
```

`base-devel` содержит компилятор и основные инструменты сборки, `git` нужен для получения исходников, а `cmake` используется при сборке Geant4 и будущих проектов.

## 3. Установка yay

`yay` — помощник для работы с AUR. Он устанавливается из исходников.

Сначала скачайте его репозиторий:

```bash
git clone https://aur.archlinux.org/yay.git
```

Перейдите в скачанную папку:

```bash
cd yay
```

Соберите и установите пакет:

```bash
makepkg -si
```

Во время установки подтвердите установку зависимостей, если система попросит это сделать.

После завершения вернитесь в домашнюю папку:

```bash
cd ..
```

Скачанная папка больше не нужна, поэтому её можно удалить:

```bash
rm -rf yay
```

Проверить установку `yay` можно командой:

```bash
yay --version
```

Если выводится номер версии, `yay` установлен правильно.

## 4. Установка Geant4

Теперь установите Geant4 из AUR:

```bash
yay -S geant4
```

`yay` автоматически найдёт пакет Geant4, скачает исходный код и необходимые зависимости, после чего начнёт сборку.

Во время установки могут появляться вопросы вида:

```text
Пакеты, для которых требуется очистить сборку?
```

или:

```text
Показать изменения?
```

Если установка выполняется впервые, можно оставить значения по умолчанию и продолжить.

После подтверждения установки начнётся компиляция Geant4.

> [!NOTE]
> Geant4 — крупный проект. Сборка может занять десятки минут и на небыстром компьютере легко растянуться примерно на час или больше. Проценты сборки растут неравномерно, поэтому долгое нахождение на одном участке не означает зависание. Если в терминале продолжают появляться строки `Building CXX object`, сборка продолжается нормально.

Не закрывайте терминал и не выключайте компьютер до окончания установки.

## 5. Что должно быть установлено

После завершения этого этапа в системе должны быть доступны:

- компилятор GCC;
- CMake;
- Git;
- `yay`;
- Geant4 и его зависимости.

Следующий этап — проверка установленного Geant4, сборка стандартного примера и запуск тестовой программы.
