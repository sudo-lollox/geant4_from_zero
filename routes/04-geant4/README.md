# Установка Geant4 на Manjaro

Этот маршрут выполняется после установки и базовой настройки Manjaro.

Здесь устанавливаются инструменты для сборки пакетов из AUR, менеджер `yay` и сам Geant4, после чего установка проверяется на стандартном примере `B1`.

## 1. Обновление системы

Перед установкой обновите систему:

```bash
sudo pacman -Syu
```

Дождитесь завершения обновления. Если обновилось ядро или большое количество системных пакетов, перед продолжением лучше перезагрузить компьютер.

## 2. Установка инструментов для сборки

Для сборки пакетов из AUR нужны стандартные инструменты разработки, Git и CMake.

Установите их командой:

```bash
sudo pacman -S --needed base-devel git cmake
```

`base-devel` содержит компилятор и основные инструменты сборки, `git` нужен для получения исходников, а `cmake` используется при сборке Geant4 и будущих проектов.

## 3. Установка yay

`yay` — помощник для работы с AUR. Он устанавливается из исходников.

Скачайте его репозиторий:

```bash
git clone https://aur.archlinux.org/yay.git
```

Перейдите в скачанную папку:

```bash
cd yay
```

Соберите и установите пакет:

```bash
makepkg -si
```

Во время установки подтвердите установку зависимостей, если система попросит это сделать.

После завершения вернитесь в домашнюю папку:

```bash
cd ..
```

Скачанная папка больше не нужна:

```bash
rm -rf yay
```

Проверьте установку:

```bash
yay --version
```

Если выводится номер версии, `yay` установлен правильно.

## 4. Установка Geant4

Установите Geant4 из AUR:

```bash
yay -S geant4
```

`yay` скачает исходный код, установит зависимости и соберёт Geant4.

Во время установки могут появляться вопросы вида:

```text
Пакеты, для которых требуется очистить сборку?
```

или:

```text
Показать изменения?
```

При первой установке можно оставить значения по умолчанию и продолжить.

> [!NOTE]
> Geant4 — крупный проект. Сборка может занять десятки минут или больше. Если в терминале продолжают появляться строки `Building CXX object`, сборка продолжается нормально.

Не закрывайте терминал и не выключайте компьютер до окончания установки.

## 5. Проверка версии

После установки проверьте Geant4:

```bash
geant4-config --version
```

На проверенной системе:

```text
11.4.2
```

## 6. Сборка стандартного примера B1

Скопируйте стандартный пример в домашнюю папку:

```bash
cp -r /usr/share/Geant4/examples/basic/B1 ~/geant4-B1
```

Перейдите в него:

```bash
cd ~/geant4-B1
```

Создайте отдельную папку сборки:

```bash
mkdir build
cd build
```

Настройте проект:

```bash
cmake ..
```

CMake должен найти установленный Geant4.

Соберите пример:

```bash
cmake --build . -j$(nproc)
```

После успешной сборки в папке `build` появится исполняемый файл `exampleB1`.

## 7. Запуск B1

На Manjaro GNOME обычно используется Wayland. Для стабильной работы Qt-визуализации запускайте B1 через XWayland:

```bash
QT_QPA_PLATFORM=xcb ./exampleB1
```

Должно открыться графическое окно Geant4 с геометрией примера `B1`.

## 8. Запуск событий

В нижней строке `Session:` окна Geant4 можно запустить нужное число событий.

Например, 100 событий:

```text
/run/beamOn 100
```

1000 событий:

```text
/run/beamOn 1000
```

Число после `/run/beamOn` — количество моделируемых событий.

> [!NOTE]
> При большом числе событий визуализатор может сообщить, что сохраняет для просмотра только первые 100 событий. Это ограничение визуализации: сами события продолжают рассчитываться полностью.

## 9. Итоговая проверка

Установка Geant4 на Manjaro завершена, если:

- `geant4-config --version` выводит установленную версию;
- `cmake ..` успешно находит Geant4;
- пример `B1` собирается без ошибок;
- команда `QT_QPA_PLATFORM=xcb ./exampleB1` открывает графическое окно;
- команда `/run/beamOn 100` выполняет 100 событий.

После этого Geant4 готов для дальнейших проектов и лабораторных работ.
