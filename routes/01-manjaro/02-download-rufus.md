# 2. Скачивание Rufus

Rufus — программа для создания загрузочной USB-флешки из ISO-образа. Устанавливать её в Windows не требуется: достаточно скачать и запустить файл.

## Скачать Rufus

1. Откройте [официальный сайт Rufus](https://rufus.ie/).
2. Пролистайте страницу до раздела **Download**.
3. Выберите стандартную версию для **Windows x64**.
4. Сохраните файл в папку загрузок.

На момент проверки пособия, 3 сентября 2026 года, актуальная версия — Rufus 4.15:

```text
rufus-4.15.exe
```

[Прямая ссылка на Rufus 4.15 для Windows x64](https://rufus.ie/downloads/rufus-4.15.exe)

> [!NOTE]
> Версия Rufus со временем изменится. Если официальный сайт предлагает более новую версию, скачайте её.

## Результат этапа

В папке загрузок должны находиться два файла:

```text
manjaro-gnome-26.1.0-260812-linux71.iso
rufus-4.15.exe
```

На следующем этапе мы запустим Rufus и запишем образ Manjaro на USB-флешку.
