# Manjaro рядом с Windows (dual boot)

Этот маршрут предназначен для установки Manjaro второй системой на компьютер, где Windows уже установлена и должна остаться рабочей.

После установки при включении компьютера можно будет выбирать, какую систему запустить: Manjaro или Windows.

> [!CAUTION]
> Ошибка при выборе диска или форматировании разделов может удалить Windows и личные файлы. Перед началом сохраните важные данные на другой накопитель.

## Этапы

1. Проверить режим загрузки Windows
2. Подготовить Windows
3. Освободить место под Manjaro
4. Создать загрузочную флешку
5. Загрузить флешку именно в режиме UEFI
6. Проверить Live-систему
7. Вручную разметить свободное место
8. Установить Manjaro
9. Проверить запуск обеих систем
10. Обновить и базово настроить Manjaro

## 1. Проверка режима загрузки Windows

Windows и Manjaro должны загружаться в одном режиме. Для современного компьютера в этом маршруте используется **UEFI**.

В Windows нажмите **Win + R**, введите:

```text
msinfo32
```

и нажмите **Enter**.

В окне «Сведения о системе» найдите строку **Режим BIOS**. Должно быть указано:

```text
UEFI
```

Если там указано **Устаревший** или **Legacy**, не продолжайте установку по этому маршруту: схема загрузки будет другой.

## 2. Подготовка Windows

### Сделать резервную копию

Скопируйте важные документы, проекты, фотографии и другие незаменимые файлы на внешний диск или в другое надёжное место.

### Приостановить BitLocker

Если системный диск зашифрован BitLocker или «Шифрованием устройства», сохраните ключ восстановления и временно приостановите защиту перед изменением разделов и настроек UEFI.

Проверить состояние можно в Windows через:

**Панель управления → Система и безопасность → Шифрование диска BitLocker**.

### Отключить быстрый запуск

Быстрый запуск оставляет файловую систему Windows в частично сохранённом состоянии. Из Linux это может выглядеть как некорректно завершённая работа Windows.

Откройте:

**Панель управления → Электропитание → Действия кнопок питания → Изменение параметров, которые сейчас недоступны**.

Снимите галочку **Включить быстрый запуск** и сохраните изменения.

После этого полностью выключите Windows:

```powershell
shutdown /s /t 0
```

## 3. Освобождение места под Manjaro

Место безопаснее освобождать средствами самой Windows.

1. Нажмите **Win + X → Управление дисками**.
2. Найдите раздел Windows, обычно это **C:**.
3. Нажмите по нему правой кнопкой и выберите **Сжать том**.
4. Укажите объём, который нужно отдать Manjaro.
5. Подтвердите сжатие.

Для Manjaro и последующей установки Geant4 рекомендуется выделить не менее **100 ГБ**. Если планируется хранить крупные сборки, наборы данных и результаты моделирования, лучше выделить больше.

После сжатия в управлении дисками должна появиться область **Не распределена**.

> [!IMPORTANT]
> Не создавайте в этой области новый том Windows и не форматируйте её в NTFS. Разделы Linux будут созданы позже в установщике Manjaro.

Не изменяйте маленькие служебные разделы Windows: EFI, Recovery и MSR.

## 4. Создание загрузочной флешки

Скачивание образа Manjaro и запись флешки полностью совпадают с первыми тремя разделами маршрута [Manjaro как основная система](../01-manjaro/README.md):

1. скачайте официальный образ Manjaro GNOME;
2. скачайте Rufus;
3. запишите ISO-образ на USB-флешку в режиме, предложенном Rufus.

> [!WARNING]
> При записи флешки все находящиеся на ней данные будут удалены.

## 5. Загрузка флешки в режиме UEFI

Это критический этап. Даже правильно записанная флешка иногда отображается в загрузочном меню дважды:

```text
UEFI: <название флешки>
<название флешки>
```

Нужно выбрать вариант, начинающийся с **UEFI:**.

Если открыть обычный вариант без UEFI, Live-система может запуститься, но установщик не сможет корректно установить загрузчик рядом с Windows.

### Через Boot Menu

1. Полностью выключите компьютер.
2. Подключите загрузочную флешку.
3. Включите компьютер и сразу нажимайте клавишу Boot Menu. Обычно это **F8**, **F11**, **F12** или **Esc**.
4. Выберите **UEFI: <название флешки>**.

### Через BIOS/UEFI

Если отдельное Boot Menu не открывается:

1. Войдите в BIOS/UEFI клавишей **Delete** или **F2**.
2. Отключите **Secure Boot**. На некоторых платах для этого выбирается **OS Type → Other OS**.
3. В разделе **Boot** поставьте вариант **UEFI: <название флешки>** первым.
4. Сохраните настройки клавишей **F10** и перезагрузитесь.

В меню Manjaro выберите видеодрайвер:

- Intel или AMD — **Boot with open source drivers**;
- NVIDIA — обычно **Boot with proprietary drivers**;
- если появляется чёрный экран или зависание, перезагрузитесь и попробуйте второй вариант.

### Проверка режима Live-системы

После загрузки рабочего стола Manjaro откройте терминал и выполните:

```bash
test -d /sys/firmware/efi && echo "UEFI" || echo "Legacy"
```

Продолжать установку нужно только при результате:

```text
UEFI
```

Если показано **Legacy**, перезагрузитесь и выберите у флешки пункт с префиксом **UEFI:**.

## 6. Проверка Live-системы

До установки проверьте:

- изображение выводится без артефактов и зависаний;
- работают клавиатура и мышь;
- доступен интернет;
- определяются нужные мониторы;
- в файловом менеджере виден диск Windows.

Затем в окне **Manjaro Hello** выберите русский язык и нажмите **Launch installer**.

## 7. Начальные страницы установщика

В установщике последовательно задайте:

1. язык — **Русский**;
2. регион и часовой пояс;
3. основную раскладку — **English (US), Default**.

Основную английскую раскладку удобно оставить для гарантированного ввода пароля. Русскую раскладку можно добавить после установки.

## 8. Ручная разметка диска

На странице разметки выберите **Ручная разметка**.

> [!CAUTION]
> Не выбирайте «Стереть накопитель»: этот вариант удалит Windows. Не форматируйте существующие разделы NTFS, Recovery и EFI.

Сначала определите:

- раздел Windows — большой раздел с файловой системой **NTFS**;
- существующий EFI-раздел — небольшой раздел **FAT32**, обычно размером от 100 МБ до 1 ГБ, с флагами **boot** и **esp**;
- область **свободного** или **неразмеченного** пространства, подготовленную в Windows.

Названия дисков могут выглядеть как `/dev/nvme0n1`, `/dev/sda` или иначе. Ориентируйтесь не только на имя, но и на модель, объём, файловую систему и существующие разделы.

### Корневой раздел Manjaro

В свободном месте создайте основной раздел:

- файловая система — **ext4**;
- точка монтирования — **/**;
- флаг — **root**, если установщик предлагает его;
- форматирование — **включено**;
- размер — почти всё выделенное под Manjaro пространство, кроме места для swap.

Для Geant4 желательно оставить корневому разделу не менее **80–100 ГБ**.

### Раздел подкачки

В оставшемся свободном месте создайте раздел:

- файловая система — **linuxswap**;
- точка монтирования не задаётся;
- размер — обычно **8–16 ГБ**.

Если нужна гибернация Manjaro, swap должен быть не меньше объёма оперативной памяти. Для обычной работы и сборки Geant4 гибернация не обязательна.

### EFI-раздел

Выберите **уже существующий EFI-раздел Windows** с файловой системой FAT32 и задайте:

- точка монтирования — **/boot/efi**;
- флаги — **boot** и **esp**;
- форматирование — **выключено**.

> [!IMPORTANT]
> EFI-раздел должен использоваться обеими системами, но его нельзя форматировать. Форматирование удалит загрузочные файлы Windows.

Отдельный второй EFI-раздел на том же диске обычно не нужен.

### Загрузчик

В поле установки загрузчика выберите диск целиком, на котором находятся Windows и EFI-раздел, например:

```text
/dev/nvme0n1
```

Не выбирайте корневой раздел вида `/dev/nvme0n1p5`.

Перед продолжением проверьте итог:

- NTFS-раздел Windows не форматируется;
- Recovery и MSR не изменяются;
- существующий FAT32 EFI смонтирован как `/boot/efi` и не форматируется;
- новый ext4-раздел смонтирован как `/` и будет отформатирован;
- новый swap отмечен как `linuxswap`;
- загрузчик устанавливается на нужный диск.

## 9. Завершение установки

После разметки:

1. создайте пользователя и пароль;
2. выберите **No Office Suite**, если офисный пакет не требуется;
3. внимательно проверьте страницу **Summary**;
4. нажмите **Установить**;
5. подтвердите изменения и дождитесь окончания.

Особенно внимательно проверьте список разделов, которые установщик собирается форматировать. В нём должны быть только новые разделы Manjaro. Существующий EFI-раздел может монтироваться, но не должен форматироваться.

После завершения выберите перезагрузку. Когда компьютер начнёт перезапускаться, извлеките установочную флешку.

## 10. Первый запуск и выбор системы

После перезагрузки должно открыться меню GRUB с пунктами Manjaro и Windows.

Сначала запустите Manjaro и убедитесь, что система загружается. Затем перезагрузите компьютер и выберите **Windows Boot Manager**.

Если Windows запускается, обе системы установлены правильно.

### Если Windows отсутствует в меню GRUB

Загрузите Manjaro, откройте терминал и выполните:

```bash
sudo pacman -S os-prober
sudo nano /etc/default/grub
```

Найдите или добавьте строку:

```text
GRUB_DISABLE_OS_PROBER=false
```

Сохраните файл: **Ctrl + O**, **Enter**, затем выйдите: **Ctrl + X**.

Обновите меню GRUB:

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

В выводе должна появиться найденная Windows. После перезагрузки пункт **Windows Boot Manager** должен быть доступен.

Даже если Windows не появилась в GRUB, её загрузчик обычно можно выбрать напрямую через Boot Menu материнской платы.

## 11. Первое обновление Manjaro

Откройте терминал и выполните:

```bash
sudo pacman -Syu
```

Введите пароль и дождитесь завершения. Символы пароля в терминале не отображаются — это нормально.

После большого обновления перезагрузите компьютер.

Добавьте русскую раскладку через:

**Настройки → Клавиатура → Источники ввода**.

Если **Ctrl + Alt + T** не открывает терминал, создайте пользовательское сочетание для команды:

```text
kgx
```

## 12. Итоговая проверка

Dual boot готов, если:

- Manjaro и Windows установлены в режиме UEFI;
- компьютер загружается без установочной флешки;
- Manjaro запускается из GRUB;
- Windows запускается из GRUB или через Windows Boot Manager;
- раздел Windows сохранился и открывается;
- корневой раздел Manjaro смонтирован как `/`;
- EFI-раздел смонтирован как `/boot/efi`;
- swap подключён;
- `sudo pacman -Syu` завершается без ошибок.

Проверить точки монтирования и swap можно командами:

```bash
findmnt / /boot/efi
swapon --show
```

На этом установка Manjaro рядом с Windows завершена. Следующий маршрут — установка Geant4 в подготовленной Manjaro.
