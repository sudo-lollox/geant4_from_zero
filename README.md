# Geant4 с нуля

Практическое пособие для студентов: установка Linux, подготовка рабочей среды, основы C++ и первые проекты в Geant4.

Пособие пишется по реальным установкам на чистые системы. Каждый обязательный шаг должен быть воспроизводим студентом без предварительного опыта работы с Linux.

## Маршрут пособия

1. [Manjaro как основная система](docs/01-manjaro/README.md)
2. Ubuntu в виртуальной машине
3. Ubuntu рядом с уже установленной системой
4. Основы работы в Linux
5. Основы C++ и CMake
6. Установка Geant4
7. Проверка установки и первый проект
8. Типовые ошибки и их исправление

Сейчас полностью оформляется первая ветка — установка Manjaro на компьютер без операционной системы. Остальные разделы будут добавляться после проверки на реальном оборудовании.

## Для кого это пособие

- для студентов, которые раньше не пользовались Linux;
- для тех, кому нужна готовая среда для работы с Geant4;
- для преподавателя, который проводит установку вместе с группой.

## Принцип

В каждой главе используются:

- только проверенные команды;
- ссылки на официальные источники;
- ожидаемый результат каждого действия;
- предупреждения перед действиями, способными удалить данные;
- отдельный раздел с типовыми ошибками.
